# ElectroHub - Electric Appliances E-Commerce Store

A modern, responsive e-commerce platform for selling premium electric appliances online.

## Features

✨ **Core Features**
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🛒 Shopping cart with add/remove/update quantity
- 💳 Checkout system with payment information
- 🔍 Product filtering by category
- ⭐ Product ratings and reviews
- 💾 Local storage for cart persistence
- 📦 Order management and history

✨ **Product Categories**
- Kitchen Appliances (Refrigerator, Microwave, Coffee Maker, Dishwasher, Blender)
- Cooling & Heating (AC, Heater)
- Laundry (Washing Machine, Dryer)
- Personal Care (Hair Dryer, Toothbrush, Vacuum)

✨ **User Experience**
- Beautiful gradient UI with modern design
- Smooth animations and transitions
- Toast notifications for user actions
- Product hover effects
- Easy navigation with sticky header

## Getting Started

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/godwinifeanyistar-coder/electric-appliance-store.git
   ```

2. Navigate to the project directory:
   ```bash
   cd electric-appliance-store
   ```

3. Open `index.html` in your web browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

4. Open your browser and go to:
   ```
   http://localhost:8000
   ```

## Usage

### Shopping
1. Browse products by scrolling or filtering by category
2. Click "Add to Cart" to add items
3. View cart by clicking the cart icon
4. Adjust quantities or remove items
5. Click "Proceed to Checkout" to complete purchase

### Checkout Process
1. Fill in shipping and billing information
2. Enter payment details (demo - not real transactions)
3. Click "Complete Purchase"
4. Receive order confirmation
